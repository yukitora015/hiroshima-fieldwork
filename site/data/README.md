# 周辺地図データ

`context.json` は、OpenStreetMap contributors によるデータを Geofabrik の中国地方向け抽出ファイルから広島市内の表示対象範囲に絞り込んだスナップショットです。元データの更新時刻は 2026-11-13 21:22:20 UTC です。

- 元データ: https://download.geofabrik.de/asia/japan/chugoku.html
- 利用条件: https://www.openstreetmap.org/copyright （ODbL）
- 道路と、閉じた単独の建物・水域・緑地の形状、および一部の名称付き施設を収録しています。すべての地物や複雑な面を網羅するものではありません。
- このファイルは自動更新されません。地図情報と通行条件が現況と異なる場合があります。

`bus-context.json` は同じ抽出データからバス経路の表示画面全域を対象に、主要道路・水域・緑地を抜き出したものです。
